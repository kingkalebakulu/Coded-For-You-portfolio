# Kaleb Akulu — Portfolio

Personal portfolio website built with **Vite + React**, **Framer Motion**, and **Lucide React**.

## Tech Stack
- **Vite** — blazing fast dev server & build tool
- **React 18** — component-based UI
- **Framer Motion** — animations & transitions
- **Lucide React** — clean icon library
- **CSS Modules** — scoped, component-level styling
- **Google Fonts** — Bebas Neue, Syne, DM Sans

## Getting Started
```bash
npm install
npm run dev
npm run build
```

## Customise
- **Your photo** — replace the Unsplash URL in `Hero.module.css` (.heroBg) and `About.jsx`
- **Email** — search `hello@kalebekulu.com` and replace throughout
- **Social links** — update hrefs in `Footer.jsx`
- **Projects** — edit the `projects` array in `Work.jsx`
